## Word Counter 📝  

**Word Counter** is a simple and efficient tool that helps you analyze text by providing real-time statistics, including:  

- **Word Count**: Total number of words in the input text.  
- **Letter Count**: Total number of characters excluding spaces.  
- **Number of Spaces**: Total spaces present in the text.  

### Features 🚀  
✅ Instant word and character count  
✅ User-friendly and minimalistic UI  
✅ Real-time updates as you type  
✅ Lightweight and fast  

### How to Use  
1. Paste or type your text into the input area.  
2. Instantly see word, letter, and space count updates.  

### Installation  
Clone the repository:  
```bash
git clone https://github.com/yourusername/word-counter.git
```
Run locally using any web server or open `index.html` in a browser.
